The five loops, in words

LoopWhat happensWhere it breaks
A · averages trap
INF structure		Averages became the default, so a clean supplier earns no credit, so nobody pays to measure, so averages stay the default. The 6% figure that anchors this is vendor-sourced and unverified.The GHG Protocol revision requires disaggregation by data type A. Note the correction: the primary-data share metric is a recommendation, not a requirement, and its name is unresolved in the draft.
B · hushing spiral
INF structure		Wrong numbers raise assurance cost, firms with good data go quiet rather than risk a greenwashing charge, so errors go unchallenged.Verification a company can show supplier by supplier.
C · labour trap
C inputs		Setup is human labour, so vendors burn cash, so they consolidate — but acquirers buy datasets, not a fix for labour.Sell the labour openly instead of hiding it behind a software multiple.
D · duplication trap
CD inputs		Each buyer group builds its own network, so the supplier answers once per network and pays for each, so participation stays thin, so no network reaches critical mass, so the next buyer builds its own. This is what killed the bank KYC utilities.One record that outputs to every network. Germany is currently paying €15–30k per SME to break the same link by subsidy A.
E · wrong-buyer loop
INF — my reading of your finding #10		Selling to whoever will answer means selling outside the buyer's entry point, so the customer never activates, so there is no case study, so the next sale leans harder on promise rather than proof, so it again goes to whoever will answer.Sell at the entry point. In compliance the entry points are dated and public.
